## Format preference for reviewable analysis

For migration reviews, import decisions, backlog triage, or anything Magnus needs to act on row-by-row, Markdown/JSON is not sufficient as the primary deliverable. Produce an `.xlsx` workbook with filterable sheets.

Recommended workbook shape:

- `Oppsummering` — key counts, recommendation, next step
- distribution tabs such as `Statusfordeling`, `Typefordeling`, `Tagfordeling`, `Ansvarligfordeling`
- a primary review sheet with an editable decision column, e.g. `Importbeslutning`
- full raw/export sheet for traceability
- current-state comparison sheet if relevant
- attachments/source references sheet if relevant

Still keep JSON/Markdown locally as working artifacts if useful, but upload the Excel file as the user-facing deliverable.
